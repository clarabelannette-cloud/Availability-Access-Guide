# Available Access Guide

A responsive, single-page wayfinding prototype for Dhoby Ghaut MRT, Plaza Singapura, and Temasek Shophouse.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Accessibility route prototype

Lift, ramp, and route status values are illustrative. Verified live status requires a facilities data feed.

The project assets are stored locally in `assets/`. Photos are compressed JPEGs; map exports remain SVG for crisp zooming.
